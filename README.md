# F1 Standings

A simple Formula 1 standings website for exploring drivers, teams, and the points battle.

## Features

- Driver podium display
- Team standings with team colors
- Favorite driver picker with team stats
- Points battle chart
- Light and dark mode
- Responsive layout for mobile and desktop

## Run the project

No installation is required. Open `index.html` in a web browser.

## Built with

- HTML
- CSS
- JavaScript

## Data note

The race-by-race chart uses illustrative sample data and does not represent official results.
