# F1 Standings

A lightweight Formula 1 standings site built with HTML, CSS, and vanilla JavaScript. Browse the driver podium and team standings, pick a favorite driver to see their team stats, and compare teams in a race-by-race points chart.

## Features

- Driver podium with first, second, and third place
- Team standings with team colors and points
- Favorite driver picker showing team position, team points, and podium finish when available
- Cumulative team points chart
- Light and dark mode
- Responsive layout for desktop and mobile

## Getting started

This project does not require installation or additional packages.

1. Download or clone the project.
2. Open `index.html` in a web browser.

## Project files

- `index.html` - page structure and content
- `style.css` - layout, colors, and responsive styles
- `script.js` - dark mode, favorite driver stats, and chart behavior

## Data note

The race-by-race points chart uses illustrative sample data. It is not official race history. The team standings and podium details are the figures currently entered in the page.
